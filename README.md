# Grugofy

**Grugofy** is a lightweight, browser-based media player that combines **local media playback** and **YouTube streaming** in a single modern interface.

No installation required—just open it in your browser and start listening.

🔗 **Live Demo:** https://grugolo.github.io/Grugofy/

---

## Features

- 🎵 Play local audio and video files
- 🔎 Search and stream content from YouTube
- 📂 Create playlists from your playback queue
- ↕️ Reorder the queue with ease
- 👆 Gesture-based controls for quick navigation
- 💾 Persistent playlists and queue using `localStorage`

---

## Getting Started

### Online

Visit the live demo and start using Grugofy instantly.

### Local

```bash
git clone https://github.com/grugolo/Grugofy.git
```

Open `index.html` in your browser.
